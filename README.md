# STOMAS — version française

Traduction française du site STOMAS https://stomas.dk, publiée sur https://stomas.fr.

- Dépôt : `tmm1982/stomas-website`, branche `stomas-fr`.
- Hébergement : projet Cloudflare Pages distinct `stomas-fr`.
- Compilation : `hugo --minify` ; dossier de sortie : `public` ; Hugo 0.168.0.
- Base : version anglaise, commit `dc884e1856b0dd4ab5bb73026ee82db1d71b6e52`.
- Le site danois et l’application restent publiés depuis `main`, la version anglaise depuis `stomasguide-en`, la version allemande depuis `stomas-de`.
- L’application danoise est exclue de cette compilation. `/app/` redirige vers https://app.stomas.dk/.

Le design, les photographies, les événements et les noms réels des organisations sont conservés. Les pages publiques et les six guides sont traduits en français et disposent d’URL françaises. Les anciennes URL danoises et anglaises redirigent vers la page correspondante. Les médias danois sont clairement signalés. Les fichiers PDF et XLSX danois d’origine ne sont pas traduits.

Les guides partagent des expériences personnelles et des informations générales. Les textes sur la sécurité dans l’eau et les prothèses phonatoires renvoient vers l’équipe soignante spécialisée. Le guide de nettoyage cite la page française du fabricant. Les sources en anglais sont identifiées comme telles. Aucune validation médicale du site n’est revendiquée.

Les coordonnées et la destination FormSubmit existante sont conservées. Le propriétaire doit vérifier la réception des messages ; aucun message de test n’a été envoyé lors de la publication.
