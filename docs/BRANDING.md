# STOMAS – sprog og terminologi

I STOMAS’ egne danske tekster bruges **medrørende** om familie, partnere, venner og andre nære personer omkring den berørte. Brug også ordet i overskrifter, navigation og sammensætninger, fx medrørendearrangementer.

Bevar den oprindelige ordlyd i officielle navne og titler, direkte citater fra andre samt eksterne kildehenvisninger og URL’er. Eksisterende tekniske ID’er og bogmærker kan bevares af hensyn til kompatibilitet.
